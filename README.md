# 🎨 CollabCanvas

> **Think together. Build together.**

CollabCanvas is a real-time collaborative workspace designed for teams to brainstorm, organize ideas, and visually build concepts together.

Create a workspace, invite collaborators, share ideas, vote on the best ones, draw on a shared canvas, and communicate through built-in voice chat.

## ✨ Features

### 🏠 Collaborative Workspaces
- Create and manage workspaces
- Share workspace IDs with collaborators
- Workspace ownership and membership
- Owner-only workspace deletion
- Secure workspace access

### 💡 Idea Management
- Create ideas with:
  - Title
  - Description
  - Category
- Edit your own ideas
- Delete your own ideas
- Search and filter ideas
- Upvote ideas

### 🎨 Real-Time Collaborative Canvas
- Freehand pen
- Eraser
- Lines
- Rectangles
- Circles
- Text
- Multiple colors
- Adjustable brush size
- Real-time synchronization
- Persistent canvas actions
- Export canvas as PNG
- Export canvas as PDF

### 🎙️ Voice Chat
- Join a workspace voice chat
- Real-time participant presence
- Mute/unmute microphone
- Leave voice chat
- Peer-to-peer audio using WebRTC

### 🔐 Authentication & Security
- Supabase authentication
- User-specific workspaces and ideas
- Owner/member authorization
- Protected API routes
- Server-side authorization checks
- Secure server-only Supabase secret key
- Users cannot modify or delete other users' ideas

### 📱 Responsive UI
- Desktop-friendly workspace
- Mobile-responsive layout
- Loading states
- Empty states
- Network error handling
- Form validation
